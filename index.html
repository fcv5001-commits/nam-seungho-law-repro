“중력은 총합을 본다.”

부분을 잘라 단순 합산하는 대신, 결속된 전체 상태와 적층 작용을 하나의 계로 다루려는 남승호 법칙 프로젝트의 공개 홈페이지입니다. 이 페이지는 프로젝트의 주장, 실험 보고값, 공개데이터 계산과 독립 검증 상태를 구분하여 제시합니다.

전체상태적층작용Γ_NS오픈데이터재현성

01. 핵심 원리

Only One → ΓNS → Ψwhole → 서로 다른 전체 고유상태

전체를 먼저 본다

단일 요소로 환원한 뒤 결과를 단순 합산하는 방법과 전체 결속 상태의 작용을 구분합니다.

동일한 공통작용

관측값마다 계수를 다시 맞추지 않고 동일한 ΓNS를 여러 전체 상태에 적용한다는 원칙을 둡니다.

예측과 검증 분리

모델 출력, 프로젝트 보고값, 공개자료 대조, 제3자 독립 재현을 서로 다른 단계로 기록합니다.

02. 관람차형 적층 수력터빈

구조

지름 2 m, 16개 버킷, 하강측 8개 버킷의 적층 상태를 이용하는 실험 장치입니다. 상단에서 순차적으로 채우고 최하점에서 배출하는 운전 구조를 전제로 합니다.

프로젝트 시험 보고

프로젝트 기록에는 연속운전에서 약 400–700 W 범위의 측정 사례와 4분 13초 운전에서 430 W가 기록되어 있습니다.

검증 원칙

단일 물통으로 환원하지 않고, 전체 버킷 상태·유량·회전속도·전기 출력·손실을 같은 시간축에서 계측하는 것을 목표로 합니다.

구분: 위 수치는 프로젝트가 보고한 시험 기록입니다. 독립 시험기관의 별도 인증값과 동일한 의미로 표시하지 않습니다.

03. 공개 검증 체계

원형식 고정 → 무입력 예측 → 사전 봉인 → 새 데이터 → 제3자 실행 → 통계검정 → 반복
오픈데이터를 이용한 계산·비교프로젝트 수행
Python 재현 코드 공개공개자료
χ² · AIC · BIC 등 정량 비교결과별 확인
완전 독립된 제3자 재현별도 증거로 판정

04. 재현성 기준

입력

원자료 출처, 파일명, 버전과 SHA-256을 기록합니다.

실행

Python 버전, 패키지 환경, 실행 명령과 설정을 공개합니다.

출력

예측값과 통계량을 저장하고 프로젝트 결과와 독립 실행 결과를 나란히 비교합니다.
