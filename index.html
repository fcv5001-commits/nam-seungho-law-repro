01 · 핵심 원리

하나의 현실 → 하나의 공통작용 → 여러 전체 고유상태. 프로젝트는 단일물통 환원, 부분에너지 단순합, 관측값별 계수 재조정을 배제하는 원칙을 둡니다.

Only One → ΓNS* → Ψwhole → {Ψ₁, Ψ₂, …} → 관측 가능한 전체상태

전체상태

부분을 떼어낸 합과 결속된 전체의 작용을 구분합니다.

공통작용

모든 대상에 동일 ΓNS*와 동일 계수를 적용한다는 원칙입니다.

사전 봉인

예측값·코드·설정·입력 해시를 먼저 고정한 뒤 비교하는 검증 절차를 지향합니다.

03 · 전체 수식 프레임

ΓNS[Ψwhole] = ∫ dτ 𝓛NS(Ψwhole, ∂Ψwhole; βNS)
δΓNS/δΨwhole = 0   ⇒   Ψwhole(n)   ⇒   𝒪n = 𝓕[Ψwhole(n)]

위 식은 프로젝트의 전체상태 원칙을 나타내는 원형식 표기입니다. 개별 분야의 정량 예측은 저장소에 공개된 구체적 모델식·입력·코드와 함께 판정합니다.

04 · 공개데이터 검증 결과

저장된 프로젝트 보고값과 현재 공개 코드 실행값을 의도적으로 분리합니다. 숫자가 같다는 것과 독립적인 자연법칙 검증 완료는 같은 판정이 아닙니다.
